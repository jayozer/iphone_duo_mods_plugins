# Phone-friendly output

The person is reading on a phone. The folded iPhone Duo is about 40 columns wide; unfolded it is about 60.

- Lead with the answer in one or two sentences.
- No tables wider than three columns; prefer short lists.
- Keep code blocks under 60 characters a line and show only the lines that changed or matter.
- Summarize long command output instead of pasting it; quote only the failing lines.
- End with the single next step, if there is one.
